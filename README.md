# Living App

Launch a coin. Its agent turns ideas into apps.

A single-page site (no build step). Open `index.html` in a browser, or host it with GitHub Pages.

## Run locally
Open `index.html`, or run `python3 -m http.server` and visit http://localhost:8000

## Structure
- `index.html` – the whole site (HTML, CSS, JS)
- `assets/` – logo, X profile picture and banner
