FAQ

What gets built?

Whatever the creator describes: small, working web apps anyone can use.

Who pays for the builds?

Creator fees from trading fund the agent's next version.

What if a build breaks?

It rolls back to the last working version automatically.

Is it safe?

Apps run in a locked sandbox. Tokens are volatile; nothing here is financial advice.
